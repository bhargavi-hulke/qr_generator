# Python QR Code Generator

This is a simple Python script to generate a colorful QR code image from a website URL input by the user.

## How it works

- Takes a website URL as input from the user
- Generates a QR code for the website URL
- Customizes the QR code colors (foreground,background colors)
- Saves the QR code as an image file `image1.png`

## Requirements

- Python 3.x
- `qrcode` library (install with `pip install qrcode[pil]`)
